# 预测模型手册

竞争比怎么算、进面线怎么估、置信度什么含义。

## 竞争比 = 预测报名人数 ÷ 招录人数

### 预测报名人数 N 的三级来源

1. **同名岗实测（A/B 级）**：在 rank 数据里找该单位「岗位名完全相同」的最近一年，
   `N = 上年报名 × (今年单位招录/上年单位招录)^0.36 × 1.05^(间隔年数)`。
   岗位名带（一）（二）序号时允许去序号弱匹配，但若 2027 拆成了多岗，
   要按拆分数把上年报名摊薄。
2. **单位均分（C 级）**：无同名岗时，用该单位历年总报名（按年加权 3:2:1.5:1:1）
   × 岗位份额 1/n27 × 开放度系数。
3. **同省中位（D 级）**：连单位都没有历史时，用同省「单岗平均报名」中位数兜底。

### 必须做的修正：历史口径陷阱

如果某岗上年**独占单位 60%+ 的报名**，而今年该单位拆成了 3 个以上岗位、
且新岗限了专业——那这个岗大概率是「不限专业年代」的主力岗，旧份额完全不可用。
此时强制降级为 C 级按均分重算。浚县税务局（三）就是典型：不限专业年代 380-550 人报名，
限专业后合理预期只有 20-110 人，不修正会虚高 4 倍。

### 开放度系数（openness）

同一单位里，不限专业的岗吃掉 2 倍报名；限 8 个以上专业类 ×1.35；限应届 ×0.72；限性别 ×0.88。

## 预估进面线

```
分 = 103.21 + 5.53 × ln(竞争比)
```

来源：河南 33 个税务岗（报名数, 进面线）回归，MAE 2.1 分。
本质是正态分位模型：进面线 = μ + σ·z，μ≈109、σ≈10.9（河南县域）。

**跨省警告**：各地考生水平差异大（江苏浙江分数高、西部边疆低），
换省使用误差 ±3 分起。数据包里只有河南的实测进面分，其他省的"预估线"只能当参考。

**百分制岗**：金融监管/证监/公安/边检笔试折算百分制，`score` 列显示 `≈` 前缀，
排序时自动沉底，绝不能和 200 分制混着看。

## 进面概率（前端曲线）

```
P(进面) = Φ((S − L) / 10.9)
L = 103.21 + 5.53 × ln(竞争比)
```

## 置信度分级（页面每个岗位都带）

| 级 | 含义 | 使用建议 |
|---|---|---|
| A | 2026 年同名岗精确实测 | 可直接参考 |
| B | 2023–2025 实测，或去序号弱匹配 | 趋势可信，绝对值±30% |
| C | 单位均分推算 | 只看相对排名 |
| D | 无任何历史 | 报名期必须核实 |

## 报名期行动线（写给用户的）

报名中后期每天公布人数。拿到实际报名数 R 后：
进面线 ≈ 103.21 + 5.53 × ln(R/招录人数)，直接对照页面速查表判断去留。
招 1 人的岗：R > 150 且估分 < 125 → 果断换。
