# 筛选规则与坑位手册

每条规则都对应真实职位表的坑。改代码前先读完。

## 门槛判定顺序（gk_lib.judge）

学历 → 学位 → 专业 → 政治面貌 → 基层年限 → 服务项目 → 应届 → 性别 → 户籍 → 证书 → 退役定向 → 隐藏门槛。
任何一个 fail 就淘汰；warn 只标记不淘汰。

## 各规则的坑

### 专业（最大杀手，淘汰 86%）
- 职位表专业栏常分本科/研究生两段：`本科：电子信息类；研究生：电子科学与技术`。
  **必须按考生学历取对应段**，本科生不能用研究生段匹配。
- `major_classes` 数组里的类名直接子串匹配；`0807` 这类代码也是子串匹配。
- **方向限定陷阱**：`电子信息工程（航空电子方向）` ≠ 电子信息工程。
  正则上：括号内不以数字开头 → 视为方向限定，淘汰；`电子信息工程（0807）` → 放行。
- 只写"计算机类"的岗位，电子信息类考生**报不了**（0807≠0809）。曾有 166 个此类岗位
  被误算进可报池，全部清除。

### 应届（淘汰 68%）
- `2027届` / `应届` → 限应届；但备注含 `非应届` / `不限应届` 时**反向放行**。
- "毕业即入伍"的考生：服役不计入择业期，毕业几年就是几年，不是应届。

### 性别（淘汰 18%）
税务系统习惯同一单位拆男女两套岗，**性别只写在备注里**，专业栏看不出来。
深泽县（三）男性 189:1、（四）女性 8:1，差 23 倍就是这个原因。

### 户籍/生源（淘汰 4%）
`限XX市户口或XX市生源` 只在备注。判定：片段里含考生省份或城市前两字 → 放行。

### 证书（淘汰 21%+）
四级 > 六级 > 法考 > 财会证书 > **软考高级 > 软考中级 > 兜底规则**。
**没问过用户就别跑**——猜 false 会错杀，
`certs` 里的键为 true 才放行：`cet4 / cet6 / legal / cpa / softadv（软考高级：信息系统项目管理师、系统架构设计师等）/ softmid（软考中级：软件设计师、网络工程师等）`。

**兜底规则（最重要）**：备注出现「任一证书 / 任一资质 / 一项资质 / 职业技能等级证书 / 职业资格证书」而上述规则都没认出的 → 默认考生无证、不可报。枚举永远追不完证书种类，兜底才可靠。
真实案例（2027 报名期）：南京/常州/富阳税务电子信息岗备注「取得信息系统项目管理师、系统架构设计师…任一证书」，专业栏完全开放、竞争仅 71:1，无软考高级证报了必被退回。
猜 true 会放进去根本报不了的岗。

### 服务基层项目（淘汰 9%）
字段「服务基层项目工作经历」≠「无限制」时，需要 identities 里有对应身份。
常见值：三支一扶 / 西部计划 / 特岗教师 / 大学生村官。

### 退役定向
- 「在军队服役5年（含）以上的高校毕业生退役士兵」→ 需 `military_years >= 5`。
  2 年义务兵报这种岗会被退回，2027 年仅浚县税务局就有 2 个这种诱饵岗。
- 「退役大学生士兵」（不带5年）→ 任何退役士兵可报。

### 隐藏门槛（备注里的一句话，漏了就白报）
| 备注原文片段 | 含义 |
|---|---|
| `2年以上商业性金融机构、经济部门工作经历` | 人行系统标配，服现役**不算** |
| `国家一级运动员` / `全国锦标赛前8名` | 公安部特勤岗，专业栏写全门类是烟雾弹 |
| `计算机二级` / `执业医师` | 特定技术岗 |

### 学历/学位
- `仅限X` → 严格等于；`X及以上` → ≥；`A或B` → 枚举。
- `与最高学历相对应的学位` → 只要有学位就放行。

## 判定输出的使用

`judge()` 返回 `fails=[(类别, 说明)]`。`screen.py --explain` 汇总淘汰原因分布，
**交付前必须看一眼 top 列表**：如果出现人行/公安部/边检的岗位，八成是新坑，先查备注原文。
